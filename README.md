# 我有话说 (dsh-result-comments)

框选 AI 回复里的一段话，点 👍 认可，或点 🤔 我有话说写一句评论；评论会变成输入框里的 tag，跟你自己的消息一起发送。

源码与问题反馈：[github.com/Liam-liyaming/dsh-result-comments](https://github.com/Liam-liyaming/dsh-result-comments)。

## 使用

1. **框选文字**：在 AI 回复里选中一段内容，松开后浮条只给出两个方向：`👍` 和 `🤔 我有话说`。
2. **👍**：立刻在输入框里放入一个「👍 认可」tag（引用这段原文），同时这段文字出现下划线和右上角 👍 徽标。
3. **🤔 我有话说**：气泡里写一句评论 → 按 `Enter` 或点「加入输入框」→ 输入框出现「🤔 评论」tag（`Shift+Enter` 换行）。可以重复框选、多次添加；每个 tag 都能单独删除（tag 上的 ×），悬停可看评论摘要。
4. **统一发送**：写好你自己的消息，正常点发送即可。每个 tag 会作为引用块进入消息（含方向、原文、你的评论），AI 与后续回溯都能看到。
5. **左侧栏「我有话说」**：本机评论历史。默认看今天，可切昨天/本周/本月/全部或选具体日期；按会话单选筛选、按原文/评论搜索；会话可折叠（今天默认展开，历史默认收起）；顶部有当前范围的摘要和 24 小时热力条。
   - **洞察**：评论词云（字号=词频、颜色=👍占比）、高频词排行（点词搜索记录）、7×24 热力、最近 8 周趋势。
   - **图谱**：会话聚合视图（圈大小=记录数、描边色=👍占比、共享关键词的会话连线）；点会话展开关键词与标注，点标注回到记录，点关键词搜索；滚轮缩放、拖动平移，缩小时自动隐藏标签。
6. **行内标记**：被标记的原文有下划线（👍 绿色实线、🤔 琥珀色虚线），emoji 徽标贴在标记文字行尾的右上角（不遮挡正文）。
   - **悬停徽标**：浮出一张小卡片，显示这条标记的方向、原文摘要和你的评论。
   - **点击徽标**：滚动定位到正文里对应的那句话（居中平滑滚动）。徽标被停在边界上时同样有效。
   - **滚出可视区时徽标不消失**：向上滚出，停靠在对话流上沿（页签下方）；向下滚出，停靠在输入框上方。多个标记同时滚出时会在同一位置重叠。
   - **选中新文字、浮条出现时**，徽标暂时让位，避免盖住浮条和评论卡片。
   - 「我有话说」面板入口仍在左侧栏，以及每轮末尾的链接。刷新后按「轮次 + 引用文字」重建。

## 安装

- 本地目录：DSH → Plugins → Add plugin → 选择本目录（或 `plugin_manager install_bundle`）；
- 发布后：`plugin_manager install_bundle` 指定 npm 包名 `dsh-result-comments`。

## 匿名使用统计

匿名统计**默认开启**，可在面板底部一键关闭（本机使用计数始终只存在本地）。开启时插件会向作者部署的腾讯云开发端点发送：

- 事件类型（`launch` / `approve` / `comment`）
- 插件版本、界面语言
- 一个随机安装 ID（首次开启时生成）

**不会发送**：选中的文字、评论内容、会话 ID、标题或任何账号信息。可在同一处随时关闭，关闭后不再发送。

统计端点的部署与查看方式见 [analytics/README.md](analytics/README.md)；发布流程见 [PUBLISHING.md](PUBLISHING.md)。

## 设计取舍与限制

- 插件不主动发消息：发送完全走输入框，由你决定随哪条消息发出、是否修改。
- 输入框里的 tag 是宿主自己的原子引用节点（QuoteNode + QuoteSummary）：内容随消息发送，显示样式由宿主决定；这不是插件自绘的组件。
- 评论记录只保存在本机浏览器，用于行内标记和历史面板；存储上限 2,000 条 / 3 MB（按时间淘汰最旧），删除输入框里的 tag 不会删除记录，需要在面板或行内卡片里删。
- 旧版本的三级记录（含「按我说的做」）读取时归并为 🤔 我的评论，不会丢失。
- 输入框暂不可用（例如正在提交）时，插入会失败并提示「输入框暂不可用」。
- 行内徽标是**覆盖层**：位置靠测量正文得到，不是正文的一部分。宿主改布局、改滚动容器或折叠内容后，徽标可能定位不准（会静默降级，不会报错）。
- 徽标归属当前会话：切换会话后，其他会话的徽标不会跟过来。
